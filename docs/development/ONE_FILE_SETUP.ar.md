## خطوات النسخة الأخف

نزّل ملف التثبيت كاملًا ثم شغّله، واختر العربية أو الإنجليزية. يحتوي الملف على
التطبيق ومشغّل WebView2 الصغير وأدوات الفيديو والإضافة. يجهز التثبيت الجديد اللغة ومجلد
تنزيلات Windows وجسر المتصفح قبل صفحة الإنهاء، ثم يفتح التطبيق مباشرة عند
اختيار تشغيله. تبقى الإعدادات والتنزيلات السابقة عند الإصلاح أو الترقية.

استُبدلت حزمة WebView2 الكاملة بمشغّل صغير لتقليل الحجم. إذا كان WebView2 موجودًا
يُعاد استخدامه؛ إن كان غائبًا ينزله المثبت تلقائيًا من Microsoft ويثبته، ويحتاج
الإنترنت حينها. عند فشل الاتصال ينبغي ظهور خطأ واضح، لا نجاح زائف.
تنزيل الملفات واستخراج معلومات الفيديو يحتاجان الإنترنت كالمعتاد. الإضافة
مرفقة؛ تفعيلها ومنحها صلاحيات المواقع يظلان داخل Chrome أو Edge بموافقتك.

لتسهيل الإضافة: افتح **الإعدادات ← تجهيز إضافة المتصفح**، ثم اختر **نسخ المسار
وفتح Chrome أو Edge**. فعّل وضع المطور، واختر تحميل إضافة غير مضغوطة، والصق
المسار في نافذة اختيار المجلد. بعدها فعّل الإضافة وافحص الاتصال من نافذتها.
يبقى المسار ظاهرًا للنسخ اليدوي عند رفض الحافظة، وتظهر عناوين صفحات الإضافات
لفتحها بنفسك إذا لم يُعثر على المتصفح أو كان مثبتًا في مكان مخصص. فتح الصفحة
لا يعني أن الإضافة ثُبّتت أو اتصلت. لا تتوفر صفحة متجر معتمدة بعد، ولذلك لا
يُدّعى تثبيت صامت أو تفعيل تلقائي.

## الاختبارات اليدوية المجمعة

استخدم حساب Windows اختبار منفصلًا بلا بيانات ZipZap أو تسجيل متصفح سابق.
لا تحذف بياناتك أو WebView2 المشترك من جهاز العمل لاختبار حالة الغياب.

1. **المظهر بالعربية والإنجليزية:** شاشات الترحيب والرخصة والمجلد والتقدم
   والإنهاء؛ الشعار والألوان والنص واضحون دون اقتطاع. جرّب لوحة المفاتيح والتكبير
   100% و150% و200%، واتجاه العربية. لا يظهر إنهاء ناجح قبل انتهاء التجهيز.
2. **أول تشغيل:** بعد تثبيت جديد، افتح التطبيق من صفحة الإنهاء. تظهر اللغة
   المختارة ومجلد تنزيلات Windows مباشرة، دون معالج إعداد إلزامي أو تنزيل
   اختبار تلقائي. يبقى معالج إعداد ZipZap متاحًا في الإعدادات.
3. **التثبيت الصامت والإصلاح والإزالة:** من مجلد المستودع، وفي حساب الاختبار
   فقط، شغّل الأمر التالي. يرفض الحالة أو التسجيل السابق عمدًا، ويتحقق من
   الإعداد التلقائي دون فتح الواجهة، ثم الاحتفاظ بالبيانات والملفات:

   ```powershell
   pwsh -File scripts/test-installer.ps1 -Installer target/release/bundle/nsis/ZipZap_0.2.0-beta.1_x64-setup.exe
   ```

4. **الترقية:** حضّر في النسخة المنشورة إعدادات وسجلًا وملفًا مكتملًا وآخر
   جزئيًا تجريبيًا، واختيار لغة أو مجلد غير متاح مؤقتًا. رقِّ وثبّت إصلاحًا؛
   تبقى اللغة والمجلد والطابور وخيارات شريط النظام وبايتات الملفات. الإزالة
   تحتفظ بالبيانات وWebView2، وتزيل فقط ربط المتصفح الذي يخص هذا التثبيت.
5. **المتطلب والإنترنت:** إذا توفرت بيئة اختبار لا تحتوي WebView2، ثبّت مع
   الإنترنت وتأكد من تنزيله وتجهيزه تلقائيًا. دون الإنترنت يجب ظهور فشل واضح
   لتلك الحالة. على جهاز يحتوي WebView2 ينبغي إعادة استخدامه ونجاح التثبيت
   دون الشبكة. إن لم تتوفر بيئة الغياب فاتركها «غير منفذة»؛ لا نحتاج آلة افتراضية.
6. **الفشل والتعافي:** أي فشل في التجهيز يعرض إرشادًا واضحًا لإعادة المحاولة
   من الإعدادات. تثبيت الجسر لا يعني تفعيل الإضافة؛ الرفض يبقى محترمًا ولا تظهر
   جاهزية متصفح غير مثبتة.
7. **تسهيل الإضافة:** اختبر زري Chrome وEdge الفعليين؛ يصل المسار المنسوخ إلى
   مجلد الإضافة المرفقة، وتنجح إضافتها من تحميل إضافة غير مضغوطة. اختبر رفض
   الحافظة والمسار اليدوي ومجلد تثبيت يحتوي مسافات أو حروفًا عربية، والمتصفح
   الغائب أو المثبت بمكان مخصص. فتح الصفحة وحده لا يُعرض نجاح اتصال.

بعد الانتهاء، يكفي ملخص «نجح / فشل / غير منفذ» لكل مجموعة مع تفاصيل أي مشكلة.
لا ترسل ملفات شخصية أو ملفات المتصفح، ولا تُطلب أرقام أداء.
