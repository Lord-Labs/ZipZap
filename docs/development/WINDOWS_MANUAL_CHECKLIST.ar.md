# اختبارات Windows المتبقية

هذه قائمة مجمعة للتنفيذ يدويًا بعد فحوص الكود. لا تعني البنود غير المنفذة نجاحًا،
ولا نحتاج إنشاء آلة افتراضية جديدة. ابدأ من مجلد المستودع على الفرع الحالي.
الفحوص المستضافة متخطاة وفق #54؛ لا تنشر هذه الاختبارات إصدارًا.

## 1. المتصفحان وعزل التشغيل — #82

أغلق أي عملية بناء أو اختبار أخرى للمشروع، ثم شغّل في PowerShell:

```powershell
New-Item -ItemType Directory -Path .research-local/closure-review -Force | Out-Null
node scripts/test-installed-browsers.mjs *> .research-local/closure-review/windows-browser-user.log
Get-Content .research-local/closure-review/windows-browser-user.log -Tail 40
node --test scripts/test-browser-cleanup.test.mjs *> .research-local/closure-review/windows-cleanup-user.log
Get-Content .research-local/closure-review/windows-cleanup-user.log -Tail 30
```

يفتح الأول Chrome ثم Edge بملفات متصفح جديدة وتطبيق ومضيف بهوية اختبار خاصة.
ينبغي نجاح تنزيل الملف وبصمته، رفض الرابط غير المسموح، إغلاق المتصفح مع بقاء
التطبيق، ثم إغلاق التطبيق وحفظ التسجيل العادي دون تغيير. يطبع مسار results.json.
الثاني يتعمد فشل الإرسال وتعليق الإغلاق، ويتحقق من إيقاف متصفح الاختبار فقط
مع الاحتفاظ بسبب الفشل. نجاحه لا يعني نجاح إرسال الرابط غير الصالح.

احتفظ بالسجلين وملف results.json. أي مهلة أو غياب نتيجة أحد المتصفحين يبقي #82 مفتوحًا.

## 2. الالتقاط والفيديو الفعليان — #89

```powershell
node scripts/test-capture-browser.mjs --video *> .research-local/closure-review/windows-capture-video-user.log
Get-Content .research-local/closure-review/windows-capture-video-user.log -Tail 40
```

يستخدم هذا أيضًا هويات وبيانات معزولة، ويختبر المتصفحين والتقاط الرابط وملكية
التنزيل والاستعادة والفيديو المباشر ومسار يوتيوب المحدود. يحتاج الإنترنت وأدوات
البناء؛ لا يثبت نجاح فيديو واحد دعم كل المواقع أو الصيغ. إعداد الصلاحيات آليًا
في هذه التجربة لا يثبت قبول نافذة صلاحيات المتصفح الحقيقية؛ افحصها في المجموعة التالية.
احتفظ بمسار النتائج والبصمات وبأي فشل، بما فيه عدم توفر صيغة يوتيوب المدعومة.

## 3. التثبيت والإعداد والصلاحيات — #88/#89/#47

هذه المجموعة تحتاج **حساب Windows اختبار منفصلًا بلا بيانات ZipZap أو تسجيل
متصفح سابق**. إذا لم يتوفر، سجّلها «غير منفذة» واترك بوابتها مفتوحة. لا تزل
WebView2 المشترك أو تغيّر تسجيل المتصفح العادي على جهاز عملك لاختبار الغياب.

المرشح المحلي من كود `980c078`: حجمه **41,194,390 بايت**، وبصمته SHA-256:
`33e231e5071842f5076a03cb6c7e9fb95f2eaf744f725c12d356f70b85d72f29`.
اسم الملف ما زال 0.2.0-beta.1، لكنه بناء main غير منشور؛ لا يغيّر ملف الإصدار
المنشور أو بصمته. فُحصت محتوياته فقط ولم يُشغّل المثبت للتحقق من سلوكه.

استخدم المثبت المحلي الحالي من target/release/bundle/nsis، وسجّل SHA-256 وإصدار
Windows وWebView2 وChrome وEdge. المثبت غير موقّع. سجل الحزمة في
[فحص المتصفحات](INSTALLED_BROWSER_QUALIFICATION.md) يميز فحص ملفات الحزمة من تشغيلها.

| الاختبار                                          | النتيجة المطلوبة                                                                                                          |
| ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------- |
| تثبيت جديد بالإنجليزية ثم العربية                 | تثبيت للمستخدم الحالي، النص والاتجاه صحيحان، ولا يبدأ التطبيق قبل اكتمال التثبيت بنجاح.                                   |
| الإعداد الأول                                     | اللغة والمجلد، اختيار المتصفح أو التخطي، ثم التحقق والإنهاء؛ رجوع وإغلاق وإعادة فتح مع بقاء التقدم.                       |
| فشل حفظ المجلد أو إلغاء اختياره                   | رسالة قابلة للتصحيح، بلا إعادة تعيين الإعدادات أو التنزيلات؛ يبقى المجلد السابق صالحًا بعد الترقية.                       |
| اختبار أول ملف الاختياري                          | لا طلب شبكة عند الإقلاع؛ بعد موافقتك يطابق الملف SHA-256 المعروض. يبقى الملف والسجل حتى تزيلهما يدويًا.                   |
| واجهة عربية/إنجليزية                              | Tab وShift+Tab وEnter وEscape، تركيز ظاهر، أصغر نافذة وتكبير 200%؛ لا أزرار محجوبة أو حالة نجاح زائفة.                    |
| رفض صلاحية الموقع في Chrome وEdge                 | الالتقاط والفيديو لا يعملان دون الموافقة، والإرسال الصريح يظل متاحًا؛ الرفض لا ينشئ مهمة.                                 |
| منح الصلاحية ثم سحبها/تعطيل الإضافة/إزالتها       | تتوقف العمليات الجديدة؛ تبقى التنزيلات المستلمة في التطبيق، ولا تُعرض جاهزية غير مثبتة.                                   |
| غياب/قدم/عدم تطابق المضيف في بيئة الاختبار        | تشخيص صادق وإعادة محاولة واضحة؛ التسجيل وحده لا يعني تثبيت الإضافة أو اتصال ملف المتصفح الحالي.                           |
| الترقية من المنشور 0.2.0-beta.1                   | احتفظ بإعدادات وسجل وملف مكتمل وآخر جزئي تجريبي؛ قارن بايتاتها قبل الترقية وبعدها. لا تحاول قراءة قاعدة أحدث بإصدار أقدم. |
| إصلاح الإصدار نفسه ثم إزالة وإعادة تثبيت          | ملفات التنزيل والحالة محفوظة، وتسجيل المضيف يُزال أو يُصلح حسب العملية دون مسح تسجيل يخص تثبيتًا آخر.                     |
| غياب WebView2 مع/دون إنترنت، إن توفرت بيئة مناسبة | سلوك تثبيت/فشل قابل للفهم، بلا نجاح زائف أو تشغيل ناقص؛ تُترك الحالة غير المتاحة غير منفذة.                               |
| طابور موقوف/مجدول ثم إعادة تشغيل                  | لا يبدأ عمل مؤجل قبل وقته؛ الاستئناف/الإيقاف والإلغاء والإغلاق إلى الصينية يعملون كما في الإعدادات.                       |

يوجد أيضًا اختبار آلي لدورة المثبت يبدأ من أول بيتا 0.1.0 في حساب الاختبار نفسه:

```powershell
pwsh -File scripts/test-installer.ps1 -Installer target/release/bundle/nsis/ZipZap_0.2.0-beta.1_x64-setup.exe -UpgradeFromFirstBeta -BrowserChecks
```

يرفض بيانات أو تسجيلًا سابقًا عمدًا. لا يغني عن الترقية من 0.2.0 أو قبول لغة
المثبت والصلاحيات الحقيقية. التعليمات التفصيلية في [التأهيل](RELEASING.md).

## 4. الإقلاع والأداء — #46

اتبع [إجراء القياس](../research/performance.md). يلزم ثلاث جلسات إقلاع Windows
حقيقية مستقلة، وفتح أول للتطبيق بعدها، وإعادات فتح دافئة وبيانات 100 و1000 صف.
لا تُعد إنشاء هوية جديدة أو إعادة فتح التطبيق إقلاعًا باردًا. اختر وقت إعادة
التشغيل بنفسك بعد حفظ عملك؛ لا ينفذ المساعد إعادة تشغيل الجهاز.

جهّز بناء أداء معزولًا بـ scripts/prepare-desktop-smoke.ps1 -Release وبيانات
benchmark-performance.mjs عند الكود نفسه، ثم استخدم measure-native-performance.ps1
مع -ColdBoot لأول تشغيل بعد الإقلاع فقط. احتفظ بملفات run.json وresults.json
وnative-results.json، ومعلومات الجهاز والنظام وWebView2. قياس ظهور مقبض النافذة
مختلف عن ظهور الجدول؛ توقيت تأكيدك اليدوي حد أعلى يشمل زمن رد فعلك، وليس زمن رسم دقيقًا.
