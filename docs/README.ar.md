# ZipZap

مدير تنزيلات مجاني ومفتوح المصدر لـ Windows، بمحرك Rust وواجهة Tauri/Svelte.
تنزيل HTTP وHTTPS، استكمال آمن، قائمة انتظار، تحديد سرعة، وواجهة عربية وإنجليزية.

**الحالة: نُشرت [النسخة التجريبية 0.2.0-beta.1](https://github.com/Lord-shaban/ZipZap/releases/tag/v0.2.0-beta.1)
لـ Windows 11 x64. النسخة غير موقعة؛ تحقق من بصمة SHA-256 قبل التثبيت.**

## الاستخدام

تضيف أعمال الجاهزية غير المنشورة على main زر **فحص الاتصال** في الإضافة، دون
طلب تنزيل أو فتح التطبيق. تميز النتيجة بين الوصول إلى الجسر وإشارة جاهزية حديثة
من التطبيق. تعرض الإعدادات اتصال Chrome وEdge الحديث بصورة منفصلة عن تسجيل
الجسر؛ غياب الاتصال لا يثبت غياب الإضافة في ملف المتصفح. راجع
[قرار الجاهزية](architecture/0010-browser-readiness.md). هذه الإضافة ليست ضمن
حزمة `0.2.0-beta.1` المنشورة.

اختر «تنزيل جديد»، وأدخل رابط HTTP/HTTPS مباشرًا، وحدد مجلد الحفظ.
تستطيع الإيقاف المؤقت والاستكمال والإلغاء من واجهة التنزيل. إغلاق التطبيق يوقف
التنزيلات النشطة مؤقتًا ويحفظ حالتها. الإعدادات تحدد عدد التنزيلات والاتصالات،
وحد السرعة المشترك، والمجلد الافتراضي، واللغة.

النسخة الحالية تضيف جدولًا وشريط أدوات وفئات للملفات: اختر اسم الملف لتفعيل
الإجراءات المتاحة، أو «إيقاف الكل مؤقتًا» للتنزيلات النشطة والمنتظرة. عند حدوث
خطأ يتوقف الإيقاف الجماعي لتراجع الرسالة وتعيد المحاولة. الفئات تعتمد على امتداد
اسم الملف ولا تنقل الملفات. البحث بالاسم أو الموقع، والضغط على عنوان الاسم أو
الحجم أو الحالة يرتب الجدول. هذه التغييرات ضمن 0.2.0-beta.1.

تحافظ النسخة الحالية أيضًا على الحالة السابقة إذا فشل حفظ أمر الإيقاف أو الاستكمال
أو الإلغاء في قاعدة البيانات. إذا تعذر حفظ حالة العامل النهائية، يظهر التنزيل
بحالة فشل ورسالة **last saved state retained**؛ أصلح مشكلة التخزين ثم أعد المحاولة.
عند إعادة الفتح يُستخدم آخر تقدم محفوظ. للتنزيلات الجديدة، تُحفظ بصمة الملف
وهويته على القرص قبل نشره؛ إذا تعطل التطبيق قبل حفظ الاكتمال، تُراجع هذه الأدلة
عند إعادة الفتح أو المحاولة دون تنزيله مجددًا. الملف المعدّل أو المستبدل أو الذي
تعذر التحقق منه يظهر **Published file conflict** ويُحتفظ به وببيانات الاستعادة.
أعد الملف الأصلي وأدلة الاستعادة أو انقل الملف المتعارض، ثم أعد المحاولة؛ لا يُستبدل
ملف موجود. التنزيلات القديمة دون أدلة نشر تحتاج تحققًا يدويًا.
راجع [حدود الاستعادة](development/ENGINE.md). هذا الإصلاح ضمن 0.2.0-beta.1.

إذا تلف ملف التجميع المؤقت أو فُقد، احتفظ بأي ملف نهائي وأضف تنزيلًا جديدًا باسم
متاح؛ إعادة المحاولة لا تعيد أدلة الملكية المفقودة. حذف السجل الفاشل يُبقي الملف النهائي.

تستعيد النسخة الحالية أيضًا قائمة التنزيلات وإعدادات النسخة الأولى في معاملة واحدة؛
إذا فشلت الاستعادة، تبقى قاعدة البيانات والملفات متاحة للإصلاح وإعادة المحاولة.
تُرفض قاعدة إصدار أحدث غير مدعوم دون إعادة ضبطها. لا تُنقص رقم مخططها ولا تحذفها
لتشغيل تطبيق أقدم؛ استخدم الإصدار المتوافق أو استعد نسخة احتياطية متسقة بعد إغلاق
جميع نسخ التطبيق. غياب قرص مجلد الحفظ لا يمنع فتح السجل. راجع سجل التأهيل لحدود فحص ترقية المثبّت. ترفع أدلة
الاكتمال مخطط قاعدة البيانات إلى 2، وأضاف المخطط 3 حفظ الطابور، وتستخدم النسخة الحالية
الآن المخطط 5 لحفظ الجدولة، بعد إضافة قواعد الفئات ومجلداتها في المخطط 4؛
لا تستطيع النسخ الأقدم فتحه. استخدم إصدارًا
متوافقًا أو نسخة احتياطية متسقة من قبل الترقية، ولا تعدّل رقم المخطط للرجوع قسرًا.

يتطلب الحفظ قرصًا يدعم hard links مثل NTFS، وقد يحتاج مؤقتًا ضعف مساحة الملف.
الملفات الموجودة لا تُستبدل، والملف المكتمل لا يُفتح تلقائيًا.

توضح نافذة الإضافة أن الحجم غير معروف أولًا، وتعرض التفاصيل تقدير أقصى مساحة
بضعف الحجم المعروف؛ هذا لا يحجز سعة ولا يضمن توفرها. إذا امتلأ قرص الحفظ أو أصبح
للقراءة فقط أو انقطع، تظهر تعليمات إصلاح عربية وإنجليزية مع الاحتفاظ بالتقدم
المحفوظ. وفر المساحة أو اسمح بالكتابة أو استعد المجلد، ثم أعد المحاولة لاستكمال
الأجزاء الصالحة. لم يُنفّذ فحص امتلاء وحدة فعلية على جهاز التحقق الحالي دون
صلاحيات مسؤول؛ حقن أخطاء التخزين في الاختبارات لا يُعد دليلًا على ذلك الفحص.

تحدد النسخة الحالية المحاولات التلقائية بثلاث محاولات. تعرض التفاصيل سبب الفشل
المترجم ورقم المحاولة وموعد الإعادة. أخطاء الشبكة والخادم المؤقتة قد تُعاد،
أما رفض الصلاحيات أو TLS أو الطلب أو التخزين فتحتاج إصلاحًا. يُحترم Retry-After
الصالح مع 429/503 حتى 30 ثانية. الإيقاف والإلغاء وإغلاق التطبيق تقطع الانتظار؛
بعد الفتح يبقى العمل متوقفًا مؤقتًا، وإعادة المحاولة تبدأ سلسلة محدودة جديدة.

إضافة Chrome وEdge ترسل الروابط باختيار صريح. فك ضغط الإضافة في مجلد ثابت،
وافتح صفحة إضافات المتصفح، وفعّل Developer mode ثم Load unpacked واختر المجلد
الذي يحتوي `manifest.json`. اختر Download with ZipZap من قائمة الرابط، أو
ألصق الرابط في نافذة الإضافة. المثبت يسجل الاتصال محليًا للمستخدم الحالي.

لا تُنقل كوكيز الجلسة؛ تنزيلات تسجيل الدخول وblob والبث المحمي غير مدعومة.
استخراج الفيديو والتحديث التلقائي والأنظمة الأخرى غير مدعومة. تعمل الجدولة
أثناء تشغيل التطبيق فقط؛ لا توقظ الجهاز. استخراج الوسائط له دراسة قرار منفصلة.
دليل الاستخدام الكامل وحدود الاستكمال في [الدليل](USER_GUIDE.md).

## مساحة العمل والجدولة

تضيف النسخة الحالية **المظهر**: داكن افتراضيًا، أو فاتح، أو اتباع مظهر النظام أثناء
التشغيل. تحفظ **الأعمدة والترتيب** عرض الأعمدة وإظهارها وفرز الجدول. غيّر العرض
بالمؤشرات أو مفاتيح الأسهم؛ يبقى اسم الملف ظاهرًا والجدول قابلًا للتمرير الأفقي.
إعادة الأعمدة الافتراضية تعدّل المسودة حتى تحفظها. لا تغيّر هذه الخيارات وجهات التنزيل.

اضغط اسم الملف بالزر الأيمن أو Shift+F10 لفتح إجراءات الملف الحقيقية بحالاتها
وأخطائها نفسها. يعود التركيز للملف عند الإغلاق، أو للجدول إذا حُذف. Ctrl+N يفتح
تنزيلًا جديدًا، وCtrl+F يبحث، وCtrl+A يحدد الظاهر، وDelete يعرض تأكيد حذف السجلات.
تحتفظ حقول النص والنوافذ بمفاتيحها المعتادة. فحوص المتصفح الآلية تشمل المظهرين
والعربية والتكبير. أفاد المشرف باختبار السيناريوهات اليدوية المطلوبة؛ وتبقى إعادة
التحقق من مرشح الإصدار ضمن المهمة #47. يعرض الإلغاء وحذف السجل من قائمة الملف
التأكيد نفسه المستخدم في شريط الأدوات. هذه الخيارات ضمن 0.2.0-beta.1.

تضيف النسخة الحالية خيار **إبقاء التنزيلات تعمل في شريط النظام عند إغلاق النافذة**
في الإعدادات، وهو معطّل افتراضيًا. عند تفعيله تختفي النافذة ويستمر الطابور نفسه.
اضغط أيقونة ZipZap لإظهاره، أو اضغط بالزر الأيمن لإظهار التطبيق أو تعليق الطابور
أو تشغيله أو الخروج. قد توجد الأيقونة ضمن الأيقونات المخفية في Windows. يتوفر
**خروج من ZipZap** أيضًا في الإعدادات؛ يحفظ تقدم العمل النشط قبل الإغلاق.
إذا تعذر إنشاء الأيقونة أو إخفاء النافذة، يغلق التطبيق بالطريقة المعتادة.
التشغيل مرة ثانية يُظهر النسخة الموجودة بدل إنشاء طابور آخر.

خيار **إشعاري عند اكتمال التنزيلات أو فشلها** مستقل ومعطّل افتراضيًا. تعرض
الإشعارات أعداد النتائج الجديدة فقط، بالعربية أو الإنجليزية، وبحد أقصى إشعار
كل خمس ثوانٍ دون أسماء أو مسارات أو روابط. لا تُعاد إشعارات السجل القديم عند
التفعيل أو إعادة الفتح، وقد يمنع Windows عرضها؛ راجع التطبيق لمعرفة النتيجة.
يجب أن يبقى التطبيق يعمل؛ شريط النظام لا يمنع السكون ولا يوقظ الجهاز ولا يسجل
تشغيلًا عند الدخول ولا يستمر بعد تسجيل الخروج. أفاد المشرف باختبار السيناريوهات
اليدوية المطلوبة؛ وتبقى إعادة التحقق من مرشح الإصدار ضمن المهمة #47. هذه الخيارات
ضمن 0.2.0-beta.1.

في النسخة الحالية، تتيح **جدولة الطابور** حفظ نافذة بدء وتعليق واحدة لتاريخ محدد أو
أيام أسبوع مختارة بالتوقيت المحلي للنظام، مع عرض موعد البدء التالي والمنطقة الزمنية.
الأيام تخص تاريخ البدء، وإذا سبق وقت التعليق وقت البدء يكون في اليوم التالي.
حفظ جدول مفعّل يعلّق المهام الجديدة حتى موعد بدء مستقبلي؛ تكتمل المهام النشطة وتبقى
المتوقفة يدويًا متوقفة. تعطيل الجدولة يحافظ على حالة الطابور؛ شغّله يدويًا عند الحاجة.
تعمل الجدولة أثناء بقاء التطبيق مفتوحًا أو في علبة النظام باختيارك، ولا توقظ الحاسوب
ولا تشغّل التطبيق. إعادة التشغيل تعلّق الطابور ولا تعيد نافذة فاتت أو بدأت بالفعل.
يُتجاوز بدء فات بأكثر من 90 ثانية بعد السكون أو تقديم الساعة، ويُطبّق التعليق المستحق.
التحكم اليدوي يستهلك المواعيد المستحقة وتبقى له الأولوية حتى الموعد المستقبلي التالي.
إرجاع الساعة لا يعيد تاريخ بدء مستهلكًا. اكتشاف تغيير المنطقة الزمنية يعلّق الطابور
وقد يتأخر حتى خمس دقائق. يُتجاوز البدء في فجوة التوقيت الصيفي، ويُرحّل التعليق
بمقدار الفجوة، ويُستخدم الظهور الأول للوقت المتكرر. عند فشل قراءة التوقيت أو حفظ
الانتقال، يُحظر بدء المهام الجديدة مع إرشادات للإصلاح. أفاد المشرف بنجاح اختبار النسخة
المعزولة في 2026-10-20؛ هذا قبول يدوي وليس مشاهدة من الوكيل، ويجب إعادة تأهيل مرشح
الإصدار ضمن #47. اختبارات الساعة المحقونة دليل منفصل.

تتيح **قواعد الفئات** في الإعدادات تعديل الأسماء والامتدادات ومجلد الحفظ المقترح،
وإضافة أو حذف مجموعات حتى 16 فئة مع إبقاء «ملفات أخرى» للأسماء غير المعروفة.
لا تُميَّز حالة الأحرف؛ اللاحقة الأطول تفوز مثل tar.gz قبل gz. يُرفض الامتداد
المكرر بين قاعدتين برسالة واضحة. تُقبل حروف وأرقام Unicode، وتُرفض المسارات
ورموز التعميم وأجزاء الامتداد الفارغة. تتبع أسماء الفئات الأصلية لغة التطبيق حتى
تغيّرها؛ تبقى الأسماء المخصصة كما كتبتها. **استعادة الفئات الافتراضية** تعيد المسودة
للمجموعات الست وتمسح اقتراحات المجلدات؛ احفظ لتثبيتها أو أغلق لإلغاء التعديل.

تعرض معاينة اسم التنزيل اليدوي مجلد الفئة للمراجعة قبل الإضافة. اختيار مجلد
صراحةً له الأولوية ويعطّل الاقتراح التلقائي لهذا التنزيل، ويمكن تفعيله مجددًا
بمربع الاختيار. تستخدم طلبات المتصفح قواعد المحرك نفسها بعد فحص اسم الخادم؛
وتبقى دفعة الروابط على مجلدها المشترك الظاهر. يبقى المجلد غير المتاح محفوظًا،
لكن يُرفض تنزيل جديد إليه حتى إصلاحه أو اختيار غيره. تعديل القواعد لا ينقل الملفات
المكتملة أو الأجزاء السابقة. تتطلب هذه الخيارات المخطط 4 حتى لا تتجاهل نسخة أقدم
اختيار المجلد. راجع سجل التأهيل لأدلة Windows والمتصفح والمثبّت وحدودها.

تضيف النسخة الحالية تحديد عدة ملفات بمربعات الاختيار ومفتاح المسافة، أو تحديد
الظاهر كله. يمكن الضغط مع Ctrl لتبديل تحديد اسم ومع Shift لتحديد نطاق حسب ترتيب
الجدول؛ تُلغى اختيارات الصفوف المخفية عند التصفية. الإجراءات الجماعية توقف أو
تستأنف أو تعيد محاولة الملفات المؤهلة، وتعرض نتيجة كل ملف وتتابع بعد فشل أحدها.
الإلغاء يحذف الأجزاء المؤقتة، وحذف السجلات ينظف أجزاء الاستعادة مع إبقاء الملفات
المكتملة. يعرض الإجراءان قائمة الملفات المتأثرة للتأكيد قبل التنفيذ.

اختر **إضافة عدة روابط** والصق حتى 100 رابط HTTP(S)، كل رابط في سطر. تُرفض الدفعة
الأكبر دون اقتطاع. اختر مجلدًا مشتركًا والبدء الآن أو الإضافة لوقت لاحق، ثم عاين
الروابط. تظهر الروابط غير الصالحة والمكررة والأسماء والأحجام المعروفة والتعارضات؛
عدّل الاسم وأعد فحصه قبل الإضافة. المعاينة لا تحجز الأسماء ولا تنشئ تنزيلات.
تبقى حالة تعليق الطابور حاكمة للبدء. تُعرض نتيجة كل رابط، وتُتخطى الروابط المقبولة
عند إعادة المحاولة. تحتفظ المحاولات بمعرّفاتها وأسمائها ومجلدها وطريقة البدء لتجنب
تكرار المهمة إذا ضاعت الإجابة؛ راجع الطابور قبل دفعة جديدة بتفاصيل مختلفة.
إغلاق المعاينة يلغي فحص البيانات الحالي ويحذف القائمة المؤقتة؛ يتعطل زر الإغلاق
ومفتاح Escape أثناء الإضافة حتى تنتهي إجابات العناصر. اختبارات
الواجهة تستخدم اتصالًا محاكى ولا تحل محل أدلة Windows الفعلية.

في النسخة الحالية، يحفظ التطبيق حالة تشغيل الطابور وتعليقه وترتيب الانتظار. **تعليق
الطابور** يمنع بدء مهام جديدة ويترك النشطة تكمل؛ تنتظر طلبات المتصفح أيضًا، مع إمكان
فحص بيانات الرابط صراحةً. **تشغيل الطابور** لا يستأنف المهام المتوقفة مؤقتًا بمفردها.
**إضافة لوقت لاحق** تنشئ تنزيلًا متوقفًا حتى تختار الاستئناف. اختر مهمة منتظرة لرؤية
أولويتها وتقديمها أو تأخيرها بلوحة المفاتيح أو الفأرة؛ فرز الجدول لا يغيّر أولوية
التنفيذ. يحافظ الاستئناف على الأولوية، وقد تؤجل حدود الخادم مهمة مبكرة. هذه الخيارات
ضمن 0.2.0-beta.1.

في النسخة الحالية، اختر تنزيلًا متوقفًا مؤقتًا أو فاشلًا ثم **استبدال الرابط**، والصق
رابط HTTP/HTTPS جديدًا بعد توقف عامله. نحتفظ بالأجزاء فقط عند إثبات المورد النهائي
نفسه بمعرّف قوي ورابط نهائي كامل وحجم معروف ونطاقات سليمة. تطابق الاسم أو الحجم
لا يكفي؛ تغيير رابط موقّع قد يتطلب البدء من الصفر. عند غياب الإثبات لا تتغير المهمة
إلا بعد موافقتك الصريحة على حذف الأجزاء. يبقى الاسم والمجلد كما هما ويبقى التنزيل
متوقفًا حتى تختار الاستئناف. إغلاق النافذة يلغي الفحص؛ أصلح نشر الملف المعلّق أولًا
إن وجدت أدلة استعادة. لا تنشر الروابط الخاصة في الصور أو التقارير.

في النسخة الحالية، يعرض **فحص اسم الملف** اقتراح الخادم للمراجعة دون تنزيل محتواه.
بدء التنزيل باسم فارغ يعرض الاقتراح أولًا؛ راجعه أو عدّله ثم ابدأ مجددًا. الاسم الذي
تكتبه لا يُستبدل. عند التعارض يمكنك قبول اسم بديل مرقّم أو كتابة اسم آخر؛ الاقتراح
لا يحجز الاسم، ويُرفض أي تعارض لاحق دون استبدال الملفات. إغلاق النافذة يلغي الفحص،
ومهلته عشر ثوانٍ. الأسماء غير الآمنة أو غير المدعومة تعود إلى اسم الرابط أو download.bin.
إذا فشل الفحص يمكنك كتابة اسم عادي والمحاولة مجددًا.

تستخدم طلبات المتصفح القواعد نفسها. يُرفض الطلب ذو الوجهة المستخدمة، ويعرض التطبيق
**مراجعة اسم الملف** لفتح أحدث رابط مرفوض كتنزيل جديد قابل للتعديل باسم بديل.
لم يدخل الطلب الأصلي الطابور. أعد إرسال الرابط إذا أغلقت المراجعة أو أعدت تشغيل
التطبيق؛ استلام المضيف للطلب في النسخة المنشورة لا يعني نجاح إضافته إلى الطابور.

تُميّز إضافة المتصفح والمضيف في النسخة الحالية بين **استلام الطلب محليًا** و**إضافته
إلى الطابور** ورفضه. لا تعني الإضافة إلى الطابور اكتمال التنزيل؛ ينتظر الطابور
المعلّق حتى تشغّله. يظهر تعارض الاسم منفصلًا عن غياب المضيف أو تعذّر تشغيل التطبيق.
إذا لم يصل التأكيد خلال 15 ثانية فقد يُعالج الطلب لاحقًا؛ راجع الطابور قبل الإرسال
مجددًا. إغلاق نافذة الإضافة يوقف عرض الرد ولا يلغي الطلب المستلم. تظهر نتيجة قائمة
الزر الأيمن في شارة الإضافة وعنوانها. حدّث التطبيق وأعد ربط المتصفح عند عدم توافق
المضيف. نتائج الطلبات محلية، بلا روابط أو أسماء ملفات، وتُحذف بعد 24 ساعة مع الاحتفاظ
بآخر 100 نتيجة كحد أقصى. أفاد المشرف باختبار السيناريوهات اليدوية المطلوبة؛
وتبقى إعادة التحقق من مرشح الإصدار ضمن المهمة #47. هذه التغييرات
ضمن 0.2.0-beta.1.

في النسخة الحالية، تحمل التنزيلات الجديدة على Windows علامة منشأ الإنترنت قبل نشر
الملف. لا نكتب الرابط الخاص في العلامة ولا نغيّر بيانات الملف؛ تُطبّق السياسة نفسها
عند استعادة نشر انقطع. لا نعيد كتابة الملفات المكتملة القديمة. إذا تعذّر حفظ العلامة
بسبب نظام الملفات أو الأذونات، يكتمل التنزيل مع تحذير مستقل. يفحص **فتح الملف** العلامة
الحالية ويطلب تأكيدًا أصليًا إذا تعذّر التحقق منها؛ الإلغاء يبقي الملف مغلقًا، و**إظهار
في المجلد** لا يشغّله. العلامة ليست شهادة أمان أو فحصًا لمكافحة الفيروسات؛ أبقِ تحذيرات
Windows مفعّلة وافتح الملفات الموثوقة فقط. هذه التغييرات ضمن 0.2.0-beta.1.

## التطوير

ثبّت Node.js 24 وRust 1.99.0 وأدوات C++ الخاصة بـ Windows وWebView2:

```sh
npm ci
node scripts/build-native.mjs
npm run desktop:dev
```

في النسخة الحالية، تعرض التفاصيل **آخر قرار للاستعادة** من حقيقة سجّلها المحرك:
نقل جديد، أو استئناف بعد التحقق من البايتات المحفوظة وهوية المورد، أو إعادة بدء آمنة
بعد حذف البيانات المحفوظة، أو استعادة ملف مكتمل بعد التحقق من بصمته وهويته.
تُعرض الحالة غير المسجّلة للتنزيلات القديمة أو التي لم تبدأ؛ عدد البايتات وحده
لا يثبت سلامة الاستئناف. قد تسجّل المحاولة التالية قرارًا مختلفًا.

افتح **ملخص الدعم** من الشريط العلوي لمعاينة إصدارات التطبيق والنظام وأعداد مجمّعة
ورموز أخطاء واستعادة محددة. تُستبعد الروابط وأسماء الملفات والمستخدمين والمسارات
والأخطاء الخام والإعدادات والكوكيز وقواعد البيانات، ولا يُرفع شيء تلقائيًا.
**تصدير المعاينة…** يحفظ النص المعروض نفسه بصيغة JSON، بحد 8 KiB، عبر نافذة الحفظ.
اختر اسمًا جديدًا؛ تبقى الملفات الموجودة. الإلغاء لا ينشئ ملف ملخص، وفشل الحفظ
يُبقي المعاينة لإعادة المحاولة. أغلق المعاينة وافتحها لتحديث الأعداد.
أكّد المشرف نجاح اختبار الحفظ والإلغاء والحفاظ على الملف الموجود على Windows
في #45؛ ويبقى تأهيل نسخة الإصدار خطوة منفصلة.

للفحص شغّل `npm run check` وفحوص Rust المذكورة في
[إعداد التطوير](development/SETUP.md). كل تغيير له Issue وفرع وPR وفحوص قبل
الدمج. العربية والإنجليزية مرحب بهما في المهام والنقاشات.

تُجرى الفحوص محليًا. أُوقف التشغيل التلقائي لاختبارات GitHub بطلب المشرف في
[المهمة #54](https://github.com/Lord-shaban/ZipZap/issues/54)؛ ولا تُعد الاختبارات
المتخطاة ناجحة. لا تُشغّل الفحوص المستضافة إلا بطلب منفصل.

يوثق [فحص التطبيق الفعلي على Windows](development/NATIVE_SMOKE.md) خطوات قابلة
للتكرار بهوية وبيانات اختبار منفصلة، مع بصمات الملفات والاستعادة والعربية ولوحة
المفاتيح. لا يحل هذا الفحص محل اختبارات المتصفحات والمثبت للإصدار القادم.

النسخة التجريبية الحالية غير موقعة؛ لا ندّعي توقيع ناشر أو سمعة SmartScreen.
تحقق من SHA-256 قبل تثبيت الملفات. المشروع بترخيص [MIT](../LICENSE) ومستقل عن IDM.
السرعة تعتمد على السيرفر والشبكة والقرص؛ لا ندّعي تفوقًا عامًا على برامج أخرى.
