# ZipZap

مدير تنزيلات مجاني ومفتوح المصدر، هدفه تنزيل الملفات باعتمادية، واستكمالها بأمان،
وتقديم واجهة واضحة. البداية على Windows، بمحرك Rust وواجهة مخطط لها باستخدام Tauri.

**الحالة الحالية: تجهيز المستودع والتخطيط. لا يوجد تطبيق أو مثبت أو إصدار متاح بعد.**

[English](../README.md) · [خطة العمل](ROADMAP.md) ·
[لوحة المتابعة](https://github.com/users/Lord-shaban/projects/12)

## نطاق أول إصدار تجريبي

- تنزيل HTTP وHTTPS، وتقسيم الملف عند دعم السيرفر لذلك.
- إيقاف مؤقت واستكمال بعد إعادة التشغيل، وقائمة انتظار وتحديد السرعة.
- واجهة Windows بالعربية والإنجليزية مع دعم اتجاه الكتابة.
- إجراء صريح «Download with ZipZap» في Chrome وEdge.
- حفظ الحالة والإعدادات محليًا دون حساب أو سيرفر خارجي.

هذه مزايا مخطط لها. التقاط كل التنزيلات تلقائيًا، واستخراج الفيديو، والجدولة بوقت،
ودعم macOS وLinux مؤجلة لما بعد النسخة التجريبية.

## طريقة العمل

كل مهمة لها Issue ومعايير قبول واعتماديات واضحة. نبدأ بفرع من `main`، ثم Pull
Request، ثم الفحوص والمراجعة والدمج. الترتيب: تجهيز المشروع، قرار المحرك وتنفيذه،
الاعتمادية وقائمة الانتظار، الواجهة، تكامل المتصفح، ثم التحقق والتوزيع.

للمساهمة في التوثيق والأدوات حاليًا، ثبّت Node.js 24 وشغّل:

```sh
npm ci
npm run check
```

الأوامر تفحص المستودع فقط؛ لا يوجد أمر لتشغيل التطبيق بعد. التفاصيل الفنية المشتركة
بالإنجليزية في [دليل المساهمة](../CONTRIBUTING.md) و[إعداد التطوير](development/SETUP.md).
العربية والإنجليزية مرحب بهما في النقاشات والمهام.

وتعتمد على الشبكة والسيرفر والقرص، وليس لغة البرمجة وحدها.
