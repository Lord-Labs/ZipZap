# ZipZap

مدير تنزيلات مجاني ومفتوح المصدر لـ Windows، بمحرك Rust وواجهة Tauri/Svelte.
تنزيل HTTP وHTTPS، استكمال آمن، قائمة انتظار، تحديد سرعة، وواجهة عربية وإنجليزية.

**الحالة: نُشرت [النسخة التجريبية 0.1.0-beta.1](https://github.com/Lord-shaban/ZipZap/releases/tag/v0.1.0-beta.1)
لـ Windows 11 x64. النسخة غير موقعة؛ تحقق من بصمة SHA-256 قبل التثبيت.**

## الاستخدام

اختر «تنزيل جديد»، وأدخل رابط HTTP/HTTPS مباشرًا، وحدد مجلد الحفظ.
تستطيع الإيقاف المؤقت والاستكمال والإلغاء من واجهة التنزيل. إغلاق التطبيق يوقف
التنزيلات النشطة مؤقتًا ويحفظ حالتها. الإعدادات تحدد عدد التنزيلات والاتصالات،
وحد السرعة المشترك، والمجلد الافتراضي، واللغة.

نسخة التطوير تضيف جدولًا وشريط أدوات وفئات للملفات: اختر اسم الملف لتفعيل
الإجراءات المتاحة، أو «إيقاف الكل مؤقتًا» للتنزيلات النشطة والمنتظرة. عند حدوث
خطأ يتوقف الإيقاف الجماعي لتراجع الرسالة وتعيد المحاولة. الفئات تعتمد على امتداد
اسم الملف ولا تنقل الملفات. البحث بالاسم أو الموقع، والضغط على عنوان الاسم أو
الحجم أو الحالة يرتب الجدول. هذه التغييرات ليست ضمن النسخة التجريبية المنشورة.

تحافظ نسخة التطوير أيضًا على الحالة السابقة إذا فشل حفظ أمر الإيقاف أو الاستكمال
أو الإلغاء في قاعدة البيانات. إذا تعذر حفظ حالة العامل النهائية، يظهر التنزيل
بحالة فشل ورسالة **last saved state retained**؛ أصلح مشكلة التخزين ثم أعد المحاولة.
عند إعادة الفتح يُستخدم آخر تقدم محفوظ. للتنزيلات الجديدة، تُحفظ بصمة الملف
وهويته على القرص قبل نشره؛ إذا تعطل التطبيق قبل حفظ الاكتمال، تُراجع هذه الأدلة
عند إعادة الفتح أو المحاولة دون تنزيله مجددًا. الملف المعدّل أو المستبدل أو الذي
تعذر التحقق منه يظهر **Published file conflict** ويُحتفظ به وببيانات الاستعادة.
أعد الملف الأصلي وأدلة الاستعادة أو انقل الملف المتعارض، ثم أعد المحاولة؛ لا يُستبدل
ملف موجود. التنزيلات القديمة دون أدلة نشر تحتاج تحققًا يدويًا.
راجع [حدود الاستعادة](development/ENGINE.md). هذا الإصلاح ليس ضمن
النسخة التجريبية المنشورة.

إذا تلف ملف التجميع المؤقت أو فُقد، احتفظ بأي ملف نهائي وأضف تنزيلًا جديدًا باسم
متاح؛ إعادة المحاولة لا تعيد أدلة الملكية المفقودة. حذف السجل الفاشل يُبقي الملف النهائي.

تستعيد نسخة التطوير أيضًا قائمة التنزيلات وإعدادات النسخة الأولى في معاملة واحدة؛
إذا فشلت الاستعادة، تبقى قاعدة البيانات والملفات متاحة للإصلاح وإعادة المحاولة.
تُرفض قاعدة إصدار أحدث غير مدعوم دون إعادة ضبطها. لا تُنقص رقم مخططها ولا تحذفها
لتشغيل تطبيق أقدم؛ استخدم الإصدار المتوافق أو استعد نسخة احتياطية متسقة بعد إغلاق
جميع نسخ التطبيق. غياب قرص مجلد الحفظ لا يمنع فتح السجل. هذه التغييرات ليست ضمن
النسخة المنشورة، وما زال تأهيل ترقية المثبت مطلوبًا للإصدار القادم. ترفع أدلة
الاكتمال مخطط قاعدة البيانات إلى 2، وتستخدم نسخة التطوير الآن المخطط 3 لحفظ الطابور؛
لا تستطيع النسخ الأقدم فتحه. استخدم إصدارًا
متوافقًا أو نسخة احتياطية متسقة من قبل الترقية، ولا تعدّل رقم المخطط للرجوع قسرًا.

يتطلب الحفظ قرصًا يدعم hard links مثل NTFS، وقد يحتاج مؤقتًا ضعف مساحة الملف.
الملفات الموجودة لا تُستبدل، والملف المكتمل لا يُفتح تلقائيًا.

توضح نافذة الإضافة أن الحجم غير معروف أولًا، وتعرض التفاصيل تقدير أقصى مساحة
بضعف الحجم المعروف؛ هذا لا يحجز سعة ولا يضمن توفرها. إذا امتلأ قرص الحفظ أو أصبح
للقراءة فقط أو انقطع، تظهر تعليمات إصلاح عربية وإنجليزية مع الاحتفاظ بالتقدم
المحفوظ. وفر المساحة أو اسمح بالكتابة أو استعد المجلد، ثم أعد المحاولة لاستكمال
الأجزاء الصالحة. لم يُنفّذ فحص امتلاء وحدة فعلية على جهاز التحقق الحالي دون
صلاحيات مسؤول؛ حقن أخطاء التخزين في الاختبارات لا يُعد دليلًا على ذلك الفحص.

تحدد نسخة التطوير المحاولات التلقائية بثلاث محاولات. تعرض التفاصيل سبب الفشل
المترجم ورقم المحاولة وموعد الإعادة. أخطاء الشبكة والخادم المؤقتة قد تُعاد،
أما رفض الصلاحيات أو TLS أو الطلب أو التخزين فتحتاج إصلاحًا. يُحترم Retry-After
الصالح مع 429/503 حتى 30 ثانية. الإيقاف والإلغاء وإغلاق التطبيق تقطع الانتظار؛
بعد الفتح يبقى العمل متوقفًا مؤقتًا، وإعادة المحاولة تبدأ سلسلة محدودة جديدة.

إضافة Chrome وEdge ترسل الروابط باختيار صريح. فك ضغط الإضافة في مجلد ثابت،
وافتح صفحة إضافات المتصفح، وفعّل Developer mode ثم Load unpacked واختر المجلد
الذي يحتوي `manifest.json`. اختر Download with ZipZap من قائمة الرابط، أو
ألصق الرابط في نافذة الإضافة. المثبت يسجل الاتصال محليًا للمستخدم الحالي.

لا تُنقل كوكيز الجلسة؛ تنزيلات تسجيل الدخول وblob والبث المحمي غير مدعومة.
استخراج الفيديو والجدولة بوقت والتحديث التلقائي والأنظمة الأخرى غير مدعومة
في النسخة المنشورة. الجدولة مخططة في M6؛ استخراج الوسائط له دراسة قرار منفصلة.
دليل الاستخدام الكامل وحدود الاستكمال في [الدليل](USER_GUIDE.md).

## التطوير

تضيف نسخة التطوير تحديد عدة ملفات بمربعات الاختيار ومفتاح المسافة، أو تحديد
الظاهر كله. يمكن الضغط مع Ctrl لتبديل تحديد اسم ومع Shift لتحديد نطاق حسب ترتيب
الجدول؛ تُلغى اختيارات الصفوف المخفية عند التصفية. الإجراءات الجماعية توقف أو
تستأنف أو تعيد محاولة الملفات المؤهلة، وتعرض نتيجة كل ملف وتتابع بعد فشل أحدها.
الإلغاء يحذف الأجزاء المؤقتة، وحذف السجلات ينظف أجزاء الاستعادة مع إبقاء الملفات
المكتملة. يعرض الإجراءان قائمة الملفات المتأثرة للتأكيد قبل التنفيذ.

اختر **إضافة عدة روابط** والصق حتى 100 رابط HTTP(S)، كل رابط في سطر. تُرفض الدفعة
الأكبر دون اقتطاع. اختر مجلدًا مشتركًا والبدء الآن أو الإضافة لوقت لاحق، ثم عاين
الروابط. تظهر الروابط غير الصالحة والمكررة والأسماء والأحجام المعروفة والتعارضات؛
عدّل الاسم وأعد فحصه قبل الإضافة. المعاينة لا تحجز الأسماء ولا تنشئ تنزيلات.
تبقى حالة تعليق الطابور حاكمة للبدء. تُعرض نتيجة كل رابط، وتُتخطى الروابط المقبولة
عند إعادة المحاولة. تحتفظ المحاولات بمعرّفاتها وأسمائها ومجلدها وطريقة البدء لتجنب
تكرار المهمة إذا ضاعت الإجابة؛ راجع الطابور قبل دفعة جديدة بتفاصيل مختلفة.
إغلاق المعاينة يلغي فحص البيانات الحالي ويحذف القائمة المؤقتة؛ يتعطل زر الإغلاق
ومفتاح Escape أثناء الإضافة حتى تنتهي إجابات العناصر. هذه المميزات ليست ضمن النسخة المنشورة، واختبارات
واجهتها تستخدم اتصالًا محاكى ولا تحل محل تأهيل Windows الفعلي.

في نسخة التطوير، يحفظ التطبيق حالة تشغيل الطابور وتعليقه وترتيب الانتظار. **تعليق
الطابور** يمنع بدء مهام جديدة ويترك النشطة تكمل؛ تنتظر طلبات المتصفح أيضًا، مع إمكان
فحص بيانات الرابط صراحةً. **تشغيل الطابور** لا يستأنف المهام المتوقفة مؤقتًا بمفردها.
**إضافة لوقت لاحق** تنشئ تنزيلًا متوقفًا حتى تختار الاستئناف. اختر مهمة منتظرة لرؤية
أولويتها وتقديمها أو تأخيرها بلوحة المفاتيح أو الفأرة؛ فرز الجدول لا يغيّر أولوية
التنفيذ. يحافظ الاستئناف على الأولوية، وقد تؤجل حدود الخادم مهمة مبكرة. هذه الخيارات
ليست ضمن النسخة التجريبية المنشورة.

في نسخة التطوير، اختر تنزيلًا متوقفًا مؤقتًا أو فاشلًا ثم **استبدال الرابط**، والصق
رابط HTTP/HTTPS جديدًا بعد توقف عامله. نحتفظ بالأجزاء فقط عند إثبات المورد النهائي
نفسه بمعرّف قوي ورابط نهائي كامل وحجم معروف ونطاقات سليمة. تطابق الاسم أو الحجم
لا يكفي؛ تغيير رابط موقّع قد يتطلب البدء من الصفر. عند غياب الإثبات لا تتغير المهمة
إلا بعد موافقتك الصريحة على حذف الأجزاء. يبقى الاسم والمجلد كما هما ويبقى التنزيل
متوقفًا حتى تختار الاستئناف. إغلاق النافذة يلغي الفحص؛ أصلح نشر الملف المعلّق أولًا
إن وجدت أدلة استعادة. لا تنشر الروابط الخاصة في الصور أو التقارير.

في نسخة التطوير، يعرض **فحص اسم الملف** اقتراح الخادم للمراجعة دون تنزيل محتواه.
بدء التنزيل باسم فارغ يعرض الاقتراح أولًا؛ راجعه أو عدّله ثم ابدأ مجددًا. الاسم الذي
تكتبه لا يُستبدل. عند التعارض يمكنك قبول اسم بديل مرقّم أو كتابة اسم آخر؛ الاقتراح
لا يحجز الاسم، ويُرفض أي تعارض لاحق دون استبدال الملفات. إغلاق النافذة يلغي الفحص،
ومهلته عشر ثوانٍ. الأسماء غير الآمنة أو غير المدعومة تعود إلى اسم الرابط أو download.bin.
إذا فشل الفحص يمكنك كتابة اسم عادي والمحاولة مجددًا.

تستخدم طلبات المتصفح القواعد نفسها. يُرفض الطلب ذو الوجهة المستخدمة، ويعرض التطبيق
**مراجعة اسم الملف** لفتح أحدث رابط مرفوض كتنزيل جديد قابل للتعديل باسم بديل.
لم يدخل الطلب الأصلي الطابور. أعد إرسال الرابط إذا أغلقت المراجعة أو أعدت تشغيل
التطبيق؛ استلام المضيف للطلب لا يعني نجاح إضافته إلى الطابور.

ثبّت Node.js 24 وRust 1.99.0 وأدوات C++ الخاصة بـ Windows وWebView2:

```sh
npm ci
node scripts/build-native.mjs
npm run desktop:dev
```

للفحص شغّل `npm run check` وفحوص Rust المذكورة في
[إعداد التطوير](development/SETUP.md). كل تغيير له Issue وفرع وPR وفحوص قبل
الدمج. العربية والإنجليزية مرحب بهما في المهام والنقاشات.

تُجرى الفحوص محليًا. أُوقف التشغيل التلقائي لاختبارات GitHub بطلب المشرف في
[المهمة #54](https://github.com/Lord-shaban/ZipZap/issues/54)؛ ولا تُعد الاختبارات
المتخطاة ناجحة. لا تُشغّل الفحوص المستضافة إلا بطلب منفصل.

يوثق [فحص التطبيق الفعلي على Windows](development/NATIVE_SMOKE.md) خطوات قابلة
للتكرار بهوية وبيانات اختبار منفصلة، مع بصمات الملفات والاستعادة والعربية ولوحة
المفاتيح. لا يحل هذا الفحص محل اختبارات المتصفحات والمثبت للإصدار القادم.

السرعة تعتمد على السيرفر والشبكة والقرص؛ لا ندّعي تفوقًا عامًا على برامج أخرى.
